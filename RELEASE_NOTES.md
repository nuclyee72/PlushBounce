## What's new
- **Automatic updates.** PlushBounce now checks for new versions and asks before installing. You can also check from the tray menu or the Display tab.

## Install
Download the **PlushBounce_…_x64-setup.exe** file below and run it. Your existing dolls and settings are kept.
From this version on, future updates install from inside the app.

Windows may show "Windows protected your PC" because the app is not code-signed. Click **More info → Run anyway**.

## Requirements
- Windows 10/11 (x64)
- WebView2 runtime (already on Windows 11; the installer fetches it if missing)
