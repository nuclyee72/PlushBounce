## What's new
- **macOS support.** PlushBounce now runs on Macs (Apple Silicon and Intel, macOS 14.2 or later). It listens to the whole system or to the apps you pick, just like on Windows, and desktop mode puts the dolls behind your desktop icons.

## Install
**Windows:** if you already have 0.4.0, the app offers this update by itself. Otherwise download **PlushBounce_…_x64-setup.exe** below and run it. Your existing dolls and settings are kept.
Windows may show "Windows protected your PC" because the app is not code-signed. Click **More info → Run anyway**.

**macOS:** download **PlushBounce_…_aarch64.dmg** (Apple Silicon: M1 and later) or **PlushBounce_…_x64.dmg** (Intel Macs), open it, and drag PlushBounce into Applications.
The app is not notarized by Apple, so the first time you open it macOS blocks it. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**. When asked, allow PlushBounce to record system audio — that is how it hears the music. Future updates install from inside the app.

## Requirements
- Windows 10/11 (x64) with the WebView2 runtime (already on Windows 11; the installer fetches it if missing)
- macOS 14.2 or later
